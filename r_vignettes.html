These vignettes provide practical guides for using R to access, organize, analyze, and visualize data. Each guide is designed to be read alongside the accompanying code, with examples that can be adapted for your own research and projects.

The goal is to make common data and analytical workflows easier to understand and reproduce, particularly for researchers working with public and spatial data.

Accessing Census Data in R

A practical introduction to accessing U.S. Census Bureau data directly through R using the tidycensus package. This guide covers how to obtain and install a Census API key, find appropriate Census variables and datasets, and download Decennial Census and American Community Survey data. It also introduces basic strategies for cleaning and reshaping Census data, working with geographic data, and automating downloads across multiple years and states.
